# Google Is Axing Cached Webpages From Search Results, Tells Everyone to Use Internet Archive Instead

![rw-book-cover](https://cdn.mos.cms.futurecdn.net/UHcv9Vhsw2SwekDHYNRAQ7-1200-80.jpg)

## Metadata
- Author: [[Christopher Harper]]
- Full Title: Google Is Axing Cached Webpages From Search Results, Tells Everyone to Use Internet Archive Instead
- Category: #articles
- Summary: Google has officially axed the feature that provided cached versions of webpages in its search results. While Google still archives search pages for now, this version of the feature is also expected to disappear soon. As an alternative, Google recommends using the Internet Archive (archive.org) to access cached versions of webpages. Bing is another option for users who still want to access cached web pages directly from the search results. This change by Google highlights the ongoing challenge of preserving the history of the internet and its media.
- URL: https://www.tomshardware.com/tech-industry/google-is-axing-cached-webpages-from-search-results-tells-everyone-to-use-internet-archive-instead

## Highlights
- On February 1st, 2024, Google's Search Liaison on Twitter [officially confirmed](https://twitter.com/searchliaison/status/1753156161509916873) that the feature has been axed. A quick and convenient link to cached versions of a webpage from the Google search result has been a staple of the search engine for well over a decade, but now it seems the most accessible version of the feature is gone entirely. ([View Highlight](https://read.readwise.io/read/01hnp5qhzmz8pfact0y7rwk5c7))
- The staple [Internet Archive (archive.org)](https://archive.org/) can't be ignored in this discussion, and Search Liaison Danny Sullivan directly mentions it as an alternative in the original tweet. ([View Highlight](https://read.readwise.io/read/01hnp5rhvcsqrhm14efy4c9rhd))
- users of the Google search engine may actually be pushed to consider Bing because of this change. Unlike Google, the Bing search engine still supports cached web pages right from the main result, so that's now at least one objective win for the cultured Bing enjoyers out there. ([View Highlight](https://read.readwise.io/read/01hnp5sb67z0eh5m42kvgk3rwn))
- Overall, this news isn't world-shaking or anything since there are still alternatives to Google's cache, and it still technically works today. ([View Highlight](https://read.readwise.io/read/01hnp5spz8qh77sq2ey714tr5b))
