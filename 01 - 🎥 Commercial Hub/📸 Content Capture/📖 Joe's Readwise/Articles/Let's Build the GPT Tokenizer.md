## Metadata
- Author: [[Andrej Karpathy]]
- Date: 2024-02-20
- Full Title: Let's Build the GPT Tokenizer
- Category: #articles
- Summary: The content discusses changes made in GPT-4, focusing on matching apostrophes, handling whitespace, and number matching. It also explains the GPT-2 encoder file structure, special tokens like "end of text" for delimiting documents, and the addition of new special tokens in GPT-4 like "fim." Model surgery is required to add special tokens. The speaker has developed a GPT-4 tokenizer code in the MBP repository.
