- Summary: Database automations in Notion are sequences of actions that occur when a specific change is made to a database. These automations consist of triggers, which cause the change, and actions, which result from the change. They can be used in various scenarios, such as assigning tasks to specific people, sending notifications in Slack, or editing page properties in other databases. Database automations are available for customers on paid plans, with limited access for non-paying users. They can be created, edited, or deleted by users with full access, except for Slack automations, which can only be edited by the creator. To pause or delete a database automation, users can access the automation menu and select the desired option.

## Highlights
- While on a database, click the ⚡ on the top right and click `+ New automation` ([View Highlight](https://read.readwise.io/read/01hnvc96v6nckbvxxgdp9qtmr0))
- • Add trigger(s). There are two kinds of triggers:
  • `Page added`: When a page is added to this database or database view, do this action
  • `Property edited`: When a property is edited in this database, do this action ([View Highlight](https://read.readwise.io/read/01hnvc9ajt0vesgnkyqf3ab1av))
- • There are four kinds of actions:
  • `Add pages to`: Add pages to a different database
  • Select the database you want to add pages to and edit properties of the new page
  • `Edit pages in`: Edit pages in a different database
  • Select the database you wish to edit and add filters to find the appropriate pages
  • Now select which property you’d like to edit. You can edit multiple properties at once
  • `Send Slack notification to…`
  • Select a Slack workspace and channel you’d like to send a notification to.
  • `Edit property in this page`
  • Select a property you’d like to edit and what change you’d like to make. ([View Highlight](https://read.readwise.io/read/01hnvca4gr50nddn1a4cs8qhk5))
