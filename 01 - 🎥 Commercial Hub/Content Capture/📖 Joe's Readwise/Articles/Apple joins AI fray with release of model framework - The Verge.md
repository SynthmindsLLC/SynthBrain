- Summary: Apple has quietly released a machine learning framework called MLX, designed to run on its chips and potentially bring generative AI apps to MacBooks. The framework allows developers to build models that run efficiently on Apple Silicon and includes a deep learning model library called MLX Data. MLX is inspired by frameworks like PyTorch and Jax, but with the added feature of shared memory, allowing tasks to be performed on supported devices without moving data. This move marks Apple's entry into the AI field, focusing on generative AI applications that competitors like Microsoft and Google have been pursuing.
