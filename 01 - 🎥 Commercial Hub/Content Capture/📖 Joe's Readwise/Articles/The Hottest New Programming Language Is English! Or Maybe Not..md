## Metadata
- Author: [[Gary Marcus]]
- Date: 2024-02-15
- Full Title: The Hottest New Programming Language Is English! Or Maybe Not.
- Category: #articles
- Summary: The article discusses the idea of programming in English as a programming language and whether it is as effective as traditional programming languages like Python or C++. The author explores the concept of programming in English, highlighting the potential benefits of eliminating the need to learn specific programming languages and allowing developers to think in their native language. However, the article also acknowledges that programming in English is not yet fully functional and presents challenges in debugging and ensuring that machines uphold their end of the programming contract. The author concludes by emphasizing the importance of formal, deterministic programming languages in specifying programming requirements precisely.
