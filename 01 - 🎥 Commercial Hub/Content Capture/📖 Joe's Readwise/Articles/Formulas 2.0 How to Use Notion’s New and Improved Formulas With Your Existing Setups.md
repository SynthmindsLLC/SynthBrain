- Summary: Notion has released Formulas 2.0, which includes improvements such as easier formula writing and editing, support for rich data outputs, and the ability to access workspace-level information. Existing formulas have been converted to maintain output compatibility, but users can now take advantage of the new rich data types by removing the conversion language. Formulas now also support local variable creation and referencing properties in related databases without the need for rollups. Notion has provided a comprehensive guide to all the changes and resources available for working with formulas.
- URL: https://www.notion.so/help/guides/new-formulas-whats-changed

## Highlights
- • **Writing and editing formulas is easier** — Formulas can be written multi-line in the editor (with tabs and comments too!), and errors are more actionable. When you write formulas, you’ll see an expanded editor box that supports multi-line editing – making it easier to view and edit long formulas. Plus, we now type-check and highlight errors directly in the editor box, so you can easily fix your syntax and ensure your formulas work. ([View Highlight](https://read.readwise.io/read/01hnvcxh593gphn087tan35gm2))
- **Formulas now support rich data outputs** — previously, formulas only supported text, numeric, and checkbox (boolean) outputs. Now, they also support displaying pages, dates, people, and lists. ([View Highlight](https://read.readwise.io/read/01hnvcxtw211te4bdnzqpce7t7))
- 1. **You can access more information directly —** formulas are now smarter, so they can reach into properties of related databases, as well as access information like member’s emails and names. ([View Highlight](https://read.readwise.io/read/01hnvcy1v9t5046cgbxeb2tpj3))
- Formulas now support local variable creation. Just like with traditional Javascript, `let` creates a variable using the name of the first argument and the value of the second argument. The third argument is where you write the rest of your formula, using your newly created variable. ([View Highlight](https://read.readwise.io/read/01hnvd059jkk8xzwzjzrbj3w71))
