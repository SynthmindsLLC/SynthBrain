# To Work Well With GenAI, You Need to Learn How to Talk to It

## Metadata
- Author: [[Jaime Teevan]]
- Date: 2023-12-15
- Full Title: To Work Well With GenAI, You Need to Learn How to Talk to It
- Category: #articles
- Summary: The latest generation of AI tools has enabled people to interact with computers in natural language, which is a huge change from previous methods. However, research shows that communicating with AI systems using prompts introduces an understandable learning curve. To improve prompts, it is important to provide more context, use the "wisdom of the crowd," rely on recognition, not recall, make it a conversation, not a single request, and try again if a prompt does not work. Good prompt support can unlock more functionality of AI tools and will be the "ribbon" of the language model.
