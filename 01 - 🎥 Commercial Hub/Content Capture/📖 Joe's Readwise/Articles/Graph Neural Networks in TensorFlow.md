- Full Title: Graph Neural Networks in TensorFlow
- Category: #articles
- Summary: Graph neural networks (GNNs) have become a powerful technique for leveraging the connectivity of graphs and the input features on nodes and edges. TensorFlow GNN 1.0 (TF-GNN) is a library that supports building and training GNNs at large scales. It provides tools for dynamic and batch subgraph sampling, allowing for efficient training on large datasets. TF-GNN also supports unsupervised training, which enables the computation of continuous representations of graph structures. The library offers a range of modeling options, from predefined models to low-level primitives for custom model building. TF-GNN Runner provides training orchestration solutions, including distributed training and GraphTensor padding. The release of TF-GNN 1.0 aims to advance the application of GNNs in TensorFlow and fuel further innovation in the field.

## Highlights
- Discrete mathematics and computer science have a long history of formalizing such networks as *[graphs](https://en.wikipedia.org/wiki/Graph_(discrete_mathematics))*, consisting of *nodes* connected by *edges* in various irregular ways. Yet most machine learning (ML) algorithms allow only for regular and uniform relations between input objects, such as a grid of pixels, a sequence of words, or no relation at all. ([View Highlight](https://read.readwise.io/read/01hp1km258fnpddp9hhtmsxmp5))
- [Graph neural networks](https://distill.pub/2021/gnn-intro/), or GNNs for short, have emerged as a powerful technique to leverage both the graph’s connectivity (as in the older algorithms [DeepWalk](http://perozzi.net/projects/deepwalk/) and [Node2Vec](https://snap.stanford.edu/node2vec/)) and the input features on the various nodes and edges. ([View Highlight](https://read.readwise.io/read/01hp1kmja7yr03jbqwtv2mnd2e))
- GNNs can make predictions for graphs as a whole (Does this molecule react in a certain way?), for individual nodes (What’s the topic of this document, given its citations?) or for potential edges (Is this product likely to be purchased together with that product?). Apart from making predictions about graphs, GNNs are a powerful tool used to bridge the chasm to more typical neural network use cases. They encode a graph's *discrete*, *relational* information in a *continuous* way so that it can be included naturally in another deep learning system. ([View Highlight](https://read.readwise.io/read/01hp1kn0szsyt8rkam2w411xwn))
- GNN is trained on a dataset of many labeled examples (~millions), but each training step consists only of a much smaller batch of training examples (say, hundreds). To scale to millions, the GNN gets trained on a stream of reasonably small subgraphs from the underlying graph. Each subgraph contains enough of the original data to compute the GNN result for the labeled node at its center and train the model. ([View Highlight](https://read.readwise.io/read/01hp1kptjf8a6bdsewjrw8dx9y))
- On those same sampled subgraphs, the GNN’s task is to compute a hidden (or latent) state at the root node; the hidden state aggregates and encodes the relevant information of the root node's neighborhood. ([View Highlight](https://read.readwise.io/read/01hp1kqw2wnwjs70r676v4tjjh))
- One classical approach is [message-passing neural networks](https://research.google/pubs/neural-message-passing-for-quantum-chemistry/). In each round of message passing, nodes receive messages from their neighbors along incoming edges and update their own hidden state from them. After *n* rounds, the hidden state of the root node reflects the aggregate information from all nodes within *n* edges (pictured below for *n* = 2). ([View Highlight](https://read.readwise.io/read/01hp1kr9ed7ecrv5qv0vpcjy9n))
- The training setup is completed by placing an output layer on top of the GNN’s hidden state for the labeled nodes, computing the *loss* (to measure the prediction error), and updating model weights by backpropagation, as usual in any neural network training. ([View Highlight](https://read.readwise.io/read/01hp1ks56rarwa6ejqqwex7vby))
- Beyond supervised training (i.e., minimizing a loss defined by labels), GNNs can also be trained in an unsupervised way (i.e., without labels). This lets us compute a *continuous* representation (or *embedding*) of the *discrete* graph structure of nodes and their features. These representations are then typically utilized in other ML systems. In this way, the discrete, relational information encoded by a graph can be included in more typical neural network use cases. TF-GNN supports a fine-grained specification of unsupervised objectives for heterogeneous graphs. ([View Highlight](https://read.readwise.io/read/01hp1ksmcz14qheed65g5p47v1))
