## Highlights
- A couple of reminders about working with `for` loops:
  • The number that we put inside `range()` in the line `for i in range(5)` is what determines the number of times the loop will repeat.
  • Only the code that's indented below the `for` loop will be repeated (or “looped” over).
  • Code inside the `for` loop needs to be **indented** in a **consistent** way.
  • The end of the indentation marks the end of the `for` loop. ([View Highlight](https://read.readwise.io/read/01j94na8jhas56fnrydscryzqt))
