## Highlights
- One of the most powerful programming tools is writing custom functions.
  These share many of the features of built-in functions but are completely customizable.
  Let's explore them by returning to turtle drawings. ([View Highlight](https://read.readwise.io/read/01j9eq14q6skdcfyafyke761f4))

- A function definition always starts with the syntax of `def`, followed by the name of the function, a set of parentheses `()`, and a colon `:`.
  The code inside the function definition needs to be **indented**. The end of the indentation is the end of the function definition. ([View Highlight](https://read.readwise.io/read/01j9eq3yh5c7qqtfz2th9vmd7t))
