## Highlights
- Information in computers is stored with binary digits that are each 000 or 1.1.1.
  A variable's range of values depends on the number of binary digits used to store it. With nnn binary digits, the variable can have a range of 2n2^n2n values.
  Computers usually store each RGB value with 888 binary digits — that's 28=2562^8 = 25628=256 possible values. The range starts at 00000000,00000000,00000000, which is 0,0,0, and ends at 11111111,11111111,11111111, which is 28−1=255.2^8 - 1 = 255.28−1=255.
