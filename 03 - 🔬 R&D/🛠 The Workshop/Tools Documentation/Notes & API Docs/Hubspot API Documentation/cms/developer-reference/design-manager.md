Design Manager


==================

Last updated: August 9, 2022

The Design Manager is a web-based integrated development environment that can optionally be used to build [templates](/docs/cms/building-blocks/templates), [modules](/docs/cms/building-blocks/modules), CSS and JavaScript. The Design Manager can be found by navigating to [**Marketing > Files and Templates > Design Tools**](https://app.hubspot.com/l/design-manager/) in the top navigation bar.

If you prefer to develop locally using your preferred code editor, workflows and technologies you can use the [CMS CLI](/docs/cms/developer-reference/local-development-cms-cli) instead. 

Regardless of whether you develop locally or utilize the Design Manager for building out assets, the entire developer file system of your account will be represented and editable in the Design Manager.

![Screenshot of HubSpot Design Manager](https://developers.hubspot.com/hubfs/designmanager%203-20-2020.png "Screenshot of HubSpot Design Manager")

Some developers or teams choose to use a [workflow where a mix of the Design Manager and local development](/docs/cms/guides/creating-an-efficient-development-workflow) are used. You can utilize the [`hs fetch`](/docs/cms/developer-reference/local-development-cms-cli#fetch) command of the [CMS CLI](/docs/cms/developer-reference/local-development-cms-cli) to pull Design Manager edits down to your local environment. Alternatively, you can prevent editing and have your entire [codebase continuously integrated with source control](/docs/cms/guides/github-integration). 

Check out this [Knowledge Base article](https://knowledge.hubspot.com/design-manager/a-quick-tour-of-the-design-manager) for a comprehensive overview of the Design Manager and its various components.

Design Manager Settings[](https://developers.hubspot.com/docs/cms/developer-reference/design-manager#design-manager-settings)
-----------------------------------------------------------------------------------------------------------------------------

The Design Manager has basic IDE settings you can configure to make the experience fit you and your workflows. A settings button appears adjacent to the help button in the bottom bar and can be used to configure the settings.

You can configure settings for:

*   Editor theme
*   Font
*   Tab size
*   Indent unit
*   Soft tabs
*   Smart Indent
*   Indent on formatting input
*   Indent with tabs
*   Line wrapping
*   Auto close brackets
*   Match brackets
*   Match tags
*   ESLint
*   and more, see [this Knowledge Base article](https://knowledge.hubspot.com/cos-general/customize-design-manager-settings?_ga=2.127499853.1751023995.1660072176-1458998919.1660072176) for a breakdown of the settings for more information.

If these features don't satisfy your needs, we highly recommend trying our [local development tools](/docs/cms/developer-reference/local-development-cms-cli) and [workflow](/docs/cms/guides/creating-an-efficient-development-workflow).
