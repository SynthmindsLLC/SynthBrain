Default themes


==================

Last updated: January 17, 2023

APPLICABLE PRODUCTS

*   ![](https://developers.hubspot.com/hubfs/raw_assets/public/developers-website/images/content_hub_icon.svg) Content Hub
    *   Starter, Professional, or Enterprise

HubSpot provides a set of default themes that content creators can use to build website pages without needing to modify the base theme. These themes are best suited for content creators who have less access to developer resources.

If you want to develop your own theme, it's recommended to start with the [HubSpot CMS Boilerplate](/docs/cms/building-blocks/themes/hubspot-cms-boilerplate). However, you can download and modify default themes using the [HubSpot CLI](/docs/cms/developer-reference/local-development-cms-cli).

Below, learn about the currently available default themes.

**Please note:** _**CMS Hub**_ _Starter_ accounts only have access to the Growth theme.

Modifying the default themes[](https://developers.hubspot.com/docs/cms/building-blocks/themes/default-themes#modifying-the-default-themes)
------------------------------------------------------------------------------------------------------------------------------------------

HubSpot’s default themes are located in a folder labeled @hubspot in the developer file system. This folder is read-only and the contents can only be modified by HubSpot. If you'd like to modify a theme, you will need to [fetch](/docs/cms/developer-reference/local-development-cms-cli#fetch) the theme you want, and then [upload](/docs/cms/developer-reference/local-development-cms-cli#upload) the theme with your changes to a different folder than @hubspot.

Default themes listing[](https://developers.hubspot.com/docs/cms/building-blocks/themes/default-themes#default-themes-listing)
------------------------------------------------------------------------------------------------------------------------------

Feel free to download our default themes using the CLI commands listed. [Learn more about the fetch command](/docs/cms/developer-reference/local-development-cms-cli#fetch) in the [CMS CLI](/docs/cms/developer-reference/local-development-cms-cli).

### Growth theme[](https://developers.hubspot.com/docs/cms/building-blocks/themes/default-themes#growth-theme)

![Growth Theme Homepage](https://developers.hubspot.com/hubfs/5Cdocs/default-themes/growth-homepage.jpg "Growth Theme Homepage")

[View Growth theme live demo](https://design-assets.hubspot.com/growth/home)

#### Industry:

Any

#### Features:

*   18 Modules
*   12 Sections
*   16 Templates

#### How to download:

hs fetch @hubspot/growth <destination-folder>
