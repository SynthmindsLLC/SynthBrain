CMS features overview


=========================

Developers and marketers can work with a number of powerful HubSpot CMS features to build their site and back it with HubSpot's world class CRM. Safely stage your site while building with HubDB, providing specific user-targeted content, and making sure your content is presented in a language with which the reader is comfortable. All right inside the HubSpot CMS.

CMS Developer Sandbox[](https://developers.hubspot.com/docs/cms/features#cms-developer-sandbox)
-----------------------------------------------------------------------------------------------

Create a free [CMS Developer Sandbox](https://offers.hubspot.com/free-cms-developer-sandbox?_ga=2.111867207.2139970322.1582658547-1060429739.1566331871) to gain access to all HubSpot developer tools and features. Use your sandbox to learn how to build great sites on [CMS Hub](https://www.hubspot.com/products/cms).

Content Search[](https://developers.hubspot.com/docs/cms/features#content-search)
---------------------------------------------------------------------------------

There’s no need for a third-party search tool. Using HubSpot’s native search engine, the HubSpot CMS’s [built-in site search functionality](/docs/cms/features/content-search) will let your visitors find the content they’re looking for.

Multi-language[](https://developers.hubspot.com/docs/cms/features#multi-language)
---------------------------------------------------------------------------------

With HubSpot’s CMS, users can create [multi-language variations](/docs/cms/features/multi-language-content) of their content. This will allow end-users to see content in the language with which they’re most comfortable. In addition, HubSpot provides tools to help developers ensure that the right language is available to the end-user.

File Manager[](https://developers.hubspot.com/docs/cms/features#file-manager)
-----------------------------------------------------------------------------

The [HubSpot File Manager](/docs/cms/features/file-manager) can be used to store and serve files for your web site. Files can be stored on the File Manager via the in-app UI, or via the [CMS CLI](/docs/cms/developer-reference/local-development-cms-cli).

Content Staging[](https://developers.hubspot.com/docs/cms/features#content-staging)
-----------------------------------------------------------------------------------

[Content Staging](/docs/cms/features/content-staging) allows web site creators to update the design and content of pages by staging the changes. These staged changes can then be published to your production site. Content staging is a CMS Hub Professional feature.

HubDB[](https://developers.hubspot.com/docs/cms/features#hubdb)
---------------------------------------------------------------

[HubDB](/docs/cms/features/hubdb) is a relational data store, much like a spreadsheet. You can create tables and manipulate data in HubDB through a user interface, or you can use the HubDB API. You can use HubSpot’s HubL markup tags to pull data straight into the CMS and dynamically generate pages based on HubDB table rows. HubDB is a CMS Hub Professional feature.

Membership[](https://developers.hubspot.com/docs/cms/features#membership)
-------------------------------------------------------------------------

Using the [Membership](/docs/cms/features/memberships) feature of CMS Hub Enterprise, you can require your CRM contacts to be logged in to view specific content of your site. Content behind membership pages can be highly personalized to the logged-in contact, and can even render Contacts, Companies, Deals and Products data from the CRM.  
Memberships functionality is a CMS Hub Enterprise feature.

Serverless Functions[](https://developers.hubspot.com/docs/cms/features#serverless-functions)
---------------------------------------------------------------------------------------------

[Serverless functions](/docs/cms/features/serverless-functions) provide a way to write server-side code that interacts with HubSpot and third-party services through APIs. Use serverless functions to add advanced capabilities to your [CMS Hub](https://www.hubspot.com/products/cms) website. Serverless Functions are a CMS Hub Enterprise feature.

HubSpot APIs[](https://developers.hubspot.com/docs/cms/features#hubspot-apis)
-----------------------------------------------------------------------------

The [HubSpot APIs](https://developers.hubspot.com/docs/overview) provides authenticated, secure access to your CMS and CRM data. The APIs is built to allow you to create a functional application or integration quickly and easily. All of the HubSpot APIs are organized around REST - if you've interacted with a RESTful API already, many of the concepts will be familiar to you.
