Plugin.addCommand() method
----------------------------

Register a command globally. Registered commands will be available from the @{link [https://help.md/Plugins/Command+palette](https://help.md/Plugins/Command+palette) Command pallete}. The command id and name will be automatically prefixed with this plugin's id and name.

**Signature:**

    addCommand(command: Command): Command;
