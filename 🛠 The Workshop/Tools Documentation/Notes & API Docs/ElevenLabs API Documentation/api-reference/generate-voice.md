Voice Generation

Generate A Random Voice
=======================

Generate a random voice based on parameters. This method returns a generated\_voice\_id in the response header, and a sample of the voice in the body. If you like the generated voice call /v1/voice-generation/create-voice with the generated\_voice\_id to create the voice.

v1

/

voice-generation

/

generate-voice

Your API key. This is required by most endpoints to access our API programatically. You can view your xi-api-key using the 'Profile' tab on the website.

string

required

`young`,

`middle_aged`,

number

required
