Feature Roadmap
===============

[Suggest Edits](/edit/feature-roadmap)

pplx-api's roadmap is as follows:

**May**

*   [x]  Deprecate several models, including codellama, mistral-7B, 8x22B and previous versions of Sonar
*   [x]  New Sonar models based on Llama 3
*   [x]  Multilingual support for Sonar models
*   [x]  `return_images` parameter for beta access users

**June**

*   [ ]  Enforce JSON grammar in responses
*   [ ]  N>1 sampling for multiple responses
*   [ ]  Model Info endpoint for listing metadata of available models
*   [ ]  Status page for API uptime and availability
