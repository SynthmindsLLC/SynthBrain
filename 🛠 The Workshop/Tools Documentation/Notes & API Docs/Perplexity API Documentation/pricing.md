Pricing
=======

pplx-api implements a usage-based pricing model. [Perplexity Pro](https://www.perplexity.ai/pro) users get $5 of free credit every month.

[Suggest Edits](/edit/pricing)

Usage is priced on tokens based on the size of the model.

| Model Parameter Count | $/1M tokens |
| --- | --- |
| 7B | $0.20 |
| 8B | $0.20 |
| 8x7B | $0.60 |
| 34B | $0.80 |
| 8x22B | $1.00 |
| 70B | $1.00 |

For `-online` models, in addition to the token charges, a flat $5 is charged per thousand requests (or half a cent per request).

| Online Model | $/1000 requests |
| --- | --- |
| llama-3-sonar-small-32k-online | $5 |
| llama-3-sonar-large-32k-online | $5 |
