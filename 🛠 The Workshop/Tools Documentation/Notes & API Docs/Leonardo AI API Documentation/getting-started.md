Getting Started
===============

Congratulations, you’re on your way to using Leonardo.Ai’s Production API to build something awesome! Whether you’re making a personal project or a service that serves millions of end-users, our Production API has you covered.

In this section, we’ll kick things off by creating your API key and using it to generate your first images through the API.

Prerequisite

[](#prerequisite)
=================================

As a prerequisite, log on to the [Leonardo web application](https://app.leonardo.ai/auth/login) or sign up to create a Leonardo account. Note that you do not need a Leonardo web app subscription to use the API. API subscription plans are separate and will be covered next.

Getting Help

[](#getting-help)
=================================

As you move through these guides and our [API documentation](/reference/), please refer to our [FAQs](/docs/api-faq) for common queries or view our step by step [Recipes](/recipes) for more detailed walkthroughs . More information about the Leonardo platform is available in our [Help Center](https://intercom.help/leonardo-ai/en/).

If you need help, don’t hesitate to reach out to us any time using the in-app support widget. You’ll find it at the bottom right of the Leonardo web app.
