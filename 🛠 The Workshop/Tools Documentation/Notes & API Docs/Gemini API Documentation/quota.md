분당 요청 수 (RPM) 한도를 늘리는 옵션
========================

bookmark\_borderbookmark 컬렉션을 사용해 정리하기 내 환경설정을 기준으로 콘텐츠를 저장하고 분류하세요.

각 모델 변형에는 관련 속도 제한 (분당 요청 수, RPM)이 있습니다. 이러한 비율 제한에 관한 자세한 내용은 [Gemini 모델](https://ai.google.dev/models/gemini?hl=ko)을 참고하세요.

Google AI SDK와 함께 Gemini API를 사용하고 현재 Google에서 제공하는 것보다 높은 비율 제한을 원한다면 무료 요금제를 계속 사용하고 프로젝트 및 사용 사례에 대한 세부정보를 포함하여 이 ['비율 한도 상향 조정 요청' 양식](https://forms.gle/ETzX94k8jf7iSotH9)을 작성하면 됩니다. 비율 한도 상향을 보장하지는 않지만 요청을 검토한 후 필요한 용량을 수용할 수 있게 되면 연락드리겠습니다.

더 높은 한도를 제공할 수 있는 [Google Cloud의 Vertex AI Platform으로 마이그레이션](https://ai.google.dev/gemini-api/docs/migrate-to-cloud?hl=ko)하는 것도 고려해 보세요. 최소한의 코드 변경으로 Vertex AI SDK를 통해 Gemini API를 계속 사용할 수 있습니다.
