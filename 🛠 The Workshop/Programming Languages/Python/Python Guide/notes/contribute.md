Python-guide is under active development, and contributors are welcome.

If you have a feature request, suggestion, or bug report, please open a new issue on [GitHub](https://github.com/kennethreitz/python-guide/). To submit patches, please send a pull request on [GitHub](https://github.com/kennethreitz/python-guide/). Once your changes get merged back in, you’ll automatically be added to the [Contributors List](https://github.com/kennethreitz/python-guide/contributors).
