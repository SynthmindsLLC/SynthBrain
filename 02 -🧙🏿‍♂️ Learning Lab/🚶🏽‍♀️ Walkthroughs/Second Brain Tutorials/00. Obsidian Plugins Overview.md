Obsidian community plugins are third-party extensions created by the user community to enhance the functionality of Obsidian, a powerful knowledge management tool that works on the principle of linking your thoughts and notes in a networked manner. These plugins are not officially part of the core Obsidian application but are developed by enthusiasts and developers who want to add new features or integrate with other services and workflows.

Community plugins can cover a wide range of functions, from simple formatting helpers to complex integrations with external applications. They allow users to customize their Obsidian experience to suit their specific needs, whether it's for writing, research, project management, or any other knowledge work. The plugins are available through Obsidian's built-in community plugins browser, where users can browse, install, and update them as needed. However, as with any third-party software, users are advised to use them with caution and be aware of potential security and privacy implications.

| Plugin | Description |
| ---- | ---- |
| Advanced Tables | Makes it easier to create markdown tables in Obsidian. |
| Calendar | Local Calendar in Obsidian, can be used for looking back on notes from specific days quickly. |
| Cannoli | Set up LLM automation within Obsidian using the local Canvas Feature |
| Checklist | Quickly create a task by doing a markdown checkbox "- [ ]" and adding specific tag (usually #todo or #todos) that will show up in the sidebar. |
| CoPilot | Local LLM, can set your own system prompt, conversation turns. Can only query an active note, though, not the whole vault. |
| Emoji Shortcodes | Just like in Discord, quickly input an emoji by clicking ":" and typing the emoji you want. |
| Kanban | Create simple Kanban board. |
| Obsidian Git | Connect to an github repo. |
| Omnisearch | Uses semantic search for find, making it better than the default search option. |
| Python Scripter | Run python scripts that reside in your vault. |
| Readwise Official | Connect to your readwise account, and funnel everything from there into here. |
| Smart Connections | Another LLM for your vault. This one can query your entire vault, but has no memory, and it's difficult to change the system prompt. |
| Tasks | A more advanced form of checklist, allowing you to set things like due date. |
| Text Generator | Use LLMs to generate text based on templates |
| Whisper | Connect OpenAI's Whisper AI for high quality speech to text. |
| Zotero Integration | Connect your Zotero, and import your annotations and meta data. |
