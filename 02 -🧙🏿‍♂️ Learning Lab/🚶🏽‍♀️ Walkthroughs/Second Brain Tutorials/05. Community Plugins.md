## What Are Community Plugins?

Community plugins in Obsidian are like a user-generated app store. They extend the functionality of Obsidian beyond its core features, allowing you to tailor your experience to your workflow. But remember, these plugins are community-made, so it's essential to ensure they're safe before using them.

## How to Access and Install Community Plugins

Let's get started with how to access and install these plugins:

1. Open your Obsidian vault.
2. Navigate to `Settings` and click on `Community Plugins`.
3. You'll see a disclaimer about the safety of community plugins. Read it carefully.
4. Click on `Turn on Community Plugins` to enable the feature.
5. Go to `Browse` to see the available plugins.

### What to Look For

When browsing plugins, pay attention to the download count. A higher number usually indicates a more trusted and widely used plugin.

## Installing the Calendar Plugin

The Calendar plugin is a great starting point. It provides a calendar view, which is not a part of Obsidian's base functionality.

```markdown
1. Find the Calendar plugin in the list.
2. Click `Install` to add it to your vault.
3. Don't forget to `Enable` the plugin after installation.
4. You can access plugin `Options` to tweak settings to your liking.
```

Once installed, you can access the Calendar from the sidebar, providing a quick view of your notes linked to dates.

## Introducing Whisper: Speech-to-Text in Obsidian

Next, we'll look at Whisper, a speech-to-text tool that transcribes your spoken words into text notes.

```markdown
1. Install Whisper by clicking `Install` and then `Enable`.
2. In the `Options`, you'll need to enter your API key from OpenAI.
```

### Getting Your OpenAI API Key

To use Whisper, you'll need an API key from OpenAI:

1. Visit [OpenAI's website](https://platform.openai.com/api-keys) and check the pricing for Whisper.
2. Create an account and set up your payment method.
3. Navigate to `API keys` and create a new key.
4. Copy the API key and paste it into Whisper's settings in Obsidian.

### Using Whisper

To start recording:

1. Click on the microphone icon in Obsidian.
2. Press the `Record` button and start speaking.
3. Hit `Stop` when you're done, and Whisper will transcribe your speech into a new note.
