## What is Cannoli?

Cannoli is an advanced feature in Obsidian that enables users to string together prompts in a chain, utilizing the notes in their vaults to inform this process. It's particularly useful for those looking to automate and streamline their workflows within Obsidian, making it easier to manage complex information systems.

## Getting Started with Cannoli

Before diving into Cannoli, it's essential to familiarize yourself with the canvas feature in Obsidian. The canvas acts like a whiteboard, allowing you to create mind maps by connecting ideas and notes visually. Understanding how to use the canvas is crucial, as Cannoli operates exclusively within this environment.

### Step 1: Accessing the Canvas

To access the canvas in Obsidian, you can either click on the "Create new canvas" button on the sidebar or use the command palette by typing "canvas" and selecting "Create new canvas." You can also set up a hotkey for quicker access. Once you're in the canvas, you can start creating boxes (nodes) and connect them to represent your ideas and notes.

### Step 2: Installing Cannoli

To install Cannoli, navigate to the settings in Obsidian, go to "Community plugins," and search for "Cannoli." Once you find it, click "Install" and then "Enable." After installation, you'll need to configure some settings, such as adding your OpenAI API key and setting a cost threshold to manage expenses associated with API calls.

### Step 3: Configuring Cannoli

After installing Cannoli, you'll need to configure it to suit your needs. This involves setting up the API key, adjusting the cost threshold, and selecting the desired GPT model. It's also possible to customize the temperature setting, which determines the creativity of the responses from the large language model.

### Step 4: Running Your First Cannoli

With Cannoli installed and configured, you're ready to run your first Cannoli. Start by creating a gray box on the canvas, which will act as your prompt to the large language model. Then, draw an arrow to a purple box, which will serve as the output. Click on the Cannoli symbol to start the process, and watch as Cannoli generates a response based on your prompt.
