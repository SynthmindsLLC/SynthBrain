# [[SynthGen Tools]]

# Purpose

# Components

## Tools
### CalendarTaskManager
Manages calendar events, tasks, and reminders.

**JSON Schema**
```json
     {
         "action": "create | update | delete",
         "type": "event | task | reminder",
         "details": {
             "title": "string",
             "date": "YYYY-MM-DD",
             "time": "HH:MM", // Optional for tasks and reminders
             "location": "string", // Optional for tasks and reminders
             "description": "string",
             "priority": "low | medium | high" // Only for tasks
         }
     }
```

### FileManager
Changes, saves, moves, and searches for files on the computer.

**JSON Schema**
```json
     {
         "action": "save | update | delete | move | search",
         "file_path": "string",
         "destination_path": "string", // Required for move action
         "search_query": "string", // Required for search action
         "content": "string" // Optional for save and update actions
     }
```

### RMTool 
Manages relationships

**JSON Schema**
 ```json
     {
         "action": "add_contact | update_contact | delete_contact",
         "contact": {
             "first_name": "string",
             "last_name": "string",
             "email": "string",
             "phone": "string",
             "notes": "string"
         }
     }
```

### ImageGenerator
Generates images based on input parameters.

**JSON Schema**:
```json
     {
         "description": "string",
         "style": "string",
         "size": "string"
     }
```

### WebSearch
Searches the web for information.

**JSON Schema**
 ```json
     {
         "query": "string"
     }
```

### CodingTool
Executes scripts.

**JSON Schema**:
```json
     {
         "language": "string",
         "script": "string",
         "inputs": {
             "input1": "value1",
             "input2": "value2"
             // Additional inputs as needed
         }
     }
```

### CommunicationTool
Sends emails or texts.

**JSON Schema**:
```json
     {
         "method": "email | text",
         "recipient": {
             "name": "string",
             "email": "string", // If method is email
             "phone": "string" // If method is text
         },
         "message": "string",
         "subject": "string" // Optional, for emails only
     }
```

### NoteTakingTool
Creates, updates, and deletes notes.

**JSON Schema**:
 ```json
     {
         "action": "create | update | delete",
         "note": {
             "title": "string",
             "content": "string",
             "tags": ["string"]
         }
     }
```
