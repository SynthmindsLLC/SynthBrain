Today marks a significant milestone for those of us who have been eagerly waiting to enhance our note-taking experience with the power of AI. We're going to explore how to integrate a large language model with our notes using two remarkable community plugins: Copilot and Smart Connections. This integration will leverage the concept of embeddings, or vector databases, to cluster text data into a matrix of numbers, making it easier for the AI to provide contextually relevant information.

## Setting Up Copilot

First, let's dive into setting up Copilot:

1. Navigate to `Settings` and then `Community Plugins` in your note-taking application.
2. Search for `Copilot` and install it.
3. Once installed, go to `Options` to configure the plugin.

### Configuration Steps:

- **Model Selection**: Choose the AI model you wish to use. Options range from standard models to turbocharged versions, and even a local AI if you prefer.
- **API Key**: You'll need an API key from OpenAI. Set up your billing information on the OpenAI platform and create a new secret key. Copy this key into the Copilot settings.
- **Conversation Context**: Set the number of conversational turns the AI should remember. This feature allows for a more natural conversation flow but be mindful of the cost per token.

### Using Copilot:

With Copilot, you can query an active note, which is particularly useful for long-form content. You have the option to use OpenAI (paid) or CohereAI (free) for embeddings. If you're tech-savvy, you can even set up a local large language model.

## Smart Connections: A Game-Changer

While Copilot is useful, Smart Connections is where the magic happens for me. Here's how to get started:

1. In `Community Plugins`, search for `Smart Connections` and enable it.
2. Enter your OpenAI API key and select your preferred model.

### Features of Smart Connections:

- **Embeddings**: Smart Connections creates embeddings for all your notes, not just the active one, allowing the AI to reference your entire note base.
- **Cost**: Although this service is not free, it is very affordable, even with a large number of notes.
- **Note Linking**: The plugin provides relevance scores between notes, making it easier to create meaningful connections.

### Personalizing Smart Connections:

To personalize the initial prompt, you'll need to edit the plugin's JavaScript file. Locate the `prompt` variable in the code and insert your custom message. Remember to save your changes, and be aware that updates to the plugin may overwrite your customizations.

## Practical Uses

One of my favorite uses for these tools is to recap the previous day. By referencing specific notes, the AI can summarize the key points, helping you to remember important tasks or events.

```markdown
Summarize [[2023-11-30]]
```

The command above will prompt the AI to provide a summary based on the linked note, offering a quick refresher of the previous day's activities.
